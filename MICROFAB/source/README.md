# ESP32 IoT Switch — Source Design Files

Original KiCad PCB and Flux.ai exports. Edit these to modify the design.

## Files
- ESP32_IoT_Switch.kicad_pcb: KiCad 6 PCB layout (open with KiCad)
- flux_export_gerbers/: Gerbers from Flux.ai (INCOMPLETE — back copper and drill empty)
- IOT_SWITCH.zip / IOT_SWITCH2.zip: Original Flux.ai project exports
- options.csv: Component options/alternatives
- overview.md.txt: Project description

## Project
IoT switch to connect/disconnect a 12V car battery using an ESP32 + relay via WiFi.
Design uses discrete PFET approach.
Flux.ai project: https://www.flux.ai/swimhack/opposite-black-robot-vacuum
