# ESP32 IoT Switch — Bare PCB Fabrication Package

Upload ESP32_IoT_Switch_Gerber_FINAL.zip to your PCB fab house.

**What this is:** Gerber files + drill file for manufacturing a bare (unpopulated) PCB.
**What you get back:** Bare circuit boards with no components soldered on.
**You still need to:** Buy and solder components yourself, or use the assembly package.

Compatible with: JLCPCB, PCBWay, OSH Park, Aisler, or any standard PCB fab.

## Specs
- 2-layer board
- 8 plated through-holes (0.8mm and 1.1mm)
- Standard 1.6mm thickness
- Generated: 2026-05-06 via KiCad 7.0.11 headless CLI
