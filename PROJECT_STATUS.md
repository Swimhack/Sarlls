# Sarlls SafeSwitch Project Status

**Last updated:** 2026-06-06
**Current phase:** Rev 2 controller PCB pre-fabrication verification
**Overall product phase:** Engineering prototype, not production-ready

## What We Are Building

SafeSwitch is intended to let a user remotely disconnect and reconnect a
vehicle battery:

`phone/app -> ESP32 controller -> onboard relay -> external 12V high-current contactor -> vehicle battery`

The active PCB is a USB-C-powered controller prototype. It validates the
ESP32, USB programming, networking, and relay-control path. It is not yet a
complete automotive product because it has no automotive 12V input/protection,
no integrated high-current disconnect, and no validated app-to-device control.

### Rev 2 Controller Board

Rev 2 is a verified pre-fabrication candidate generated by
`scripts/route_pcb.py`.

- J1 is edge-mounted and D1 is moved away from the connector.
- Production PCB, BOM, CPL, DRC report, Gerbers, and drill files were regenerated.
- DRC gate result: 0 blocking findings.
- Remaining DRC findings: 26 intentional J1 edge-clearance exceptions and
  11 silkscreen warnings.
- Release Gerber ZIP:
  `production/Sarlls_IoT_Switch_Rev2_JLCPCB.zip`

Rev 2 still needs assembler review of the USB-C via-in-pad escapes, confirmation
of SW1/SW2/J2 part-footprint matches, and final DFM/placement-preview review
before ordering.

## Software Status

  981,256 bytes, 74%.
- Hardware test firmware compiles with the `huge_app` partition:
  1,635,343 bytes, 51%.
- Android Gradle tests pass.
- The Android app is currently a UI prototype and does not communicate with
  the ESP32.
- ESP32 production firmware exposes a local-network web interface/API; this is
  not yet integrated with the Android app.
